Os SHAs identificam as árvores consultadas. A instalação baixou as branches padrão logo após essa consulta; não é um lockfile de dependências executáveis.

Neste projeto: aplicar os princípios de hierarquia, estados, foco e consistência ao WinUI 3. Não instalar React, Playwright ou uma integração Figma apenas para validar uma interface nativa. A busca `layout --stack winui` do UI/UX Pro Max retornou orientações para ItemsRepeater e VisualStateManager, ambos preservados no Format Kit.

As skills de revisão web ficam disponíveis para os projetos compatíveis. O pacote de QA foi selecionado por tarefa; não foram instalados módulos de reuniões, estudos de caso ou geração de ícones sem demanda.
